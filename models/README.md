# MIRAGE model assets

This directory separates third-party model assets from the React interface and Python application code.

- `arabic_sign_mobilenetv2/`: reserved for a verified Arabic-specific MobileNetV2 checkpoint, labels, provenance, and license. No checkpoint is installed.
- `gesture_command_mediapipe/`: official MediaPipe Gesture Recognizer bundle for non-linguistic interface gestures.

Do not put datasets, arbitrary training checkpoints, or dependencies larger than 1 GB here without recording their exact size and obtaining the required approval first.
